Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Page introductions and supporting text

Give page titles, summaries and short category labels a shared hierarchy without changing document heading order.

Example project

A clear introduction

The summary introduces the page with a readable line length and a larger text size.

Lead text can also be used independently.

Use h1 on a real page; this nested documentation example uses .intro-title on h3 to retain the heading hierarchy. --flair-intro-title-size, --flair-intro-space, --flair-lead-size, --flair-lead-measure and --flair-eyebrow-* control the treatment.

HTML and Sass 
<header class="demo-page-intro">
  <p class="demo-eyebrow">Example project</p>
  <h3 class="intro-title">A clear introduction</h3>
  <p class="lead">The summary introduces the page with a readable line length and a larger text size.</p>
</header>
<p class="demo-lead">Lead text can also be used independently.</p>
@use "flair";

.demo-page-intro { @extend %p-page-intro; }
.demo-eyebrow { @extend %d-eyebrow; }
.demo-lead { @extend %d-lead; }

Using the theme presets in a project

The theme selector on this website uses the same exported mixins available to consumers. Theme imports emit no CSS or font downloads until included.

Shared theme settings

Choose a theme in the site controls to see all examples change together.

Inspect themed controls

Available overrides are theme-ink (Dark), theme-paper, theme-vivid, theme-github and theme-material. theme-base supplies the Monochrome defaults. Include base first and then one optional override. Website layout tokens and theme-selection behaviour are not exported.

HTML and Sass 
<div class="demo-card"><h3>Shared theme settings</h3><p>Choose a theme in the site controls to see all examples change together.</p><a href="/library/controls/">Inspect themed controls</a></div>
@use "flair";

/* Choose one preset at the application root. Fonts are loaded by the application. */

  @include flair.theme-base;
  @include flair.theme-paper;
