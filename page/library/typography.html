Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Using the theme presets in a project

The theme selector on this website uses the same exported mixins available to consumers. Theme imports emit no CSS or font downloads until included.

Shared theme settings

Choose a theme in the site controls to see all examples change together.

Inspect themed controls

Available overrides are theme.ink (Ink), theme.paper, theme.vivid, theme.github and theme.material. theme.base supplies the Monochrome defaults. Include base first and then one optional override. Each theme provides light and dark colours. Set html data-theme to light or dark to override the system preference, or omit the attribute to follow the browser.

The palette and the named layer

A theme is built in two layers. Nine numbered slots hold the raw colours, and the named --theme-* properties map them onto meaning. A new theme replaces the nine and inherits every mapping; where a colour does not come from the palette, it sets the named property directly instead.

The swatches below are live. Change the theme at the top of the page and watch the same nine slots take new values, while every definition in the library keeps reading the same names.

  1. --pal-1 Foreground text
  2. --pal-2 Base surface, behind the page
  3. --pal-3 Raised surface: panels, controls, striped rows
  4. --pal-4 Border
  5. --pal-5 Muted foreground: captions, metadata, placeholders
  6. --pal-6 Accent: links, focus, current state
  7. --pal-7 Foreground on top of the accent
  8. --pal-8 Positive
  9. --pal-9 Negative

Every slot is a light-dark() pair, so one palette serves both schemes without a second block of colours or any JavaScript. A theme needing more than nine adds further slots of its own, and maps them the same way.

This is why a layout can be built in black and white and coloured later: the definitions never name a colour, only a role. flair.defaults supplies the monochrome palette and the mapping, and a theme preset replaces it.

	@include flair.color-scheme;

	// Nine values are the whole of a theme's colour.

	--pal-2: light-dark(#fff, #0d1117);
	--pal-3: light-dark(#f6f8fa, #161b22);
