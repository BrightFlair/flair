Disclosures

Native expandable content and an optional modal presentation.

Expandable content

Details and summary provide keyboard and pointer interaction without JavaScript. The native marker indicates the state.

Connection settings

Additional information is hidden until the reader expands it.

Grouped disclosures

Independent panels may remain open together. Add a shared name to details elements when only one should remain open.

Where are styles defined?

In Sass placeholders, extended onto application selectors.

Can I override the spacing?

Yes. Set the appropriate inherited CSS properties on the containing scope.

Does this require JavaScript?

No. The browser handles this interaction.

HTML and Sass 
<div class="demo-accordion">

Dialog

Modal dialogs fill the screen on mobile, with scrollable content and stacked actions. From 40rem they become centred panels. Without JavaScript the dialog content appears inline. The website enhancement enables modal opening, Escape dismissal and return of focus to the opener.

Example dialog

This dialog demonstrates presentation and focus handling. It does not save or delete anything.

HTML and Sass 
<div class="demo-stack" data-dialog-example>
	<button class="demo-button" type="button" data-dialog-open hidden>
		Open example dialog
	</button>
	<dialog class="demo-dialog" aria-labelledby="example-dialog-title" open>
		<div class="demo-stack">
			<h3 id="example-dialog-title">Example dialog</h3>
			<p>
				This dialog demonstrates presentation and focus handling. It does not save or
				delete anything.
			</p>
			<form method="dialog">
				<button class="demo-button" data-dialog-close hidden>Close dialog</button>
			</form>
		</div>
	</dialog>
</div>
@use "flair";

.demo-stack {
	@extend %p-stack;
}

.demo-dialog {
	@extend %o-dialog;
}

.demo-button {
	@extend %o-button;
}

Dialog with primary and negative actions

Both actions close the dialog and report the selected choice below. This is a presentation example; no draft is saved or discarded.

Keep this draft?

Choose the primary action to keep the example draft, or the negative action to discard it.

HTML and Sass 
<div class="demo-stack" data-dialog-example>
	<button class="demo-button" type="button" data-dialog-open hidden>Open action dialog</button>
	<dialog class="demo-dialog" aria-labelledby="action-dialog-title" open>
		<div class="demo-stack">
			<h3 id="action-dialog-title">Keep this draft?</h3>
			<p>Choose the primary action to keep the example draft, or the negative action to discard it.</p>
			<form class="demo-actions" method="dialog">
				<button class="demo-danger-button" type="submit" value="discard" data-dialog-result="Discard selected. No draft was changed." data-dialog-close hidden>Discard draft</button>
				<button class="demo-primary" type="submit" value="keep" data-dialog-result="Keep selected. No draft was changed." data-dialog-close hidden>Keep draft</button>
			</form>
		</div>
	</dialog>
	<p class="demo-output" role="status" data-dialog-status></p>
</div>
@use "flair";

	@extend %p-stack;

.demo-dialog {
	@extend %o-dialog;

.demo-actions {

}

	@extend %o-button;
}

.demo-primary {

Dialog with a required field

Submit requires a project name. Native form validation keeps the dialog open when the field is empty; Cancel and Escape still dismiss it. The value is not sent or saved.

Name the example project

HTML and Sass 
<div class="demo-stack" data-dialog-example>
	<button class="demo-button" type="button" data-dialog-open hidden>Open form dialog</button>
	<dialog class="demo-dialog" aria-labelledby="form-dialog-title" open>
		<form class="demo-form" method="dialog">
			<h3 id="form-dialog-title">Name the example project</h3>
			<label>
				<span>Project name (required)</span>
				<input name="project-name" required aria-describedby="dialog-name-help" />
				<span class="field-help" id="dialog-name-help">Required before submitting this example.</span>
			</label>
			<div class="actions">

			</div>
		</form>
	</dialog>

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.
