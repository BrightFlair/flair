Highlight decoration

%d-highlight adds a border with four square markers outside its corners. It can frame text or a whole container. Inline text uses display: inline-block so wrapped lines share one box.

Highlighted text

This longer text wraps inside one highlighted box.

The same decoration can frame a container at its available width.

Markers use the text colour; the border inherits the theme’s border colour. Override --flair-highlight-marker-size, --flair-highlight-border-width or --flair-highlight-border-color to adjust them. The decoration uses ::before and needs space outside its border without clipping by an ancestor.

HTML and Sass 
<p><span class="demo-highlight">Highlighted text</span></p>
<div class="demo-highlight-wrap">
	<p><span class="demo-highlight">This longer text wraps inside one highlighted box.</span></p>
</div>
<div class="demo-highlight">
	<p>The same decoration can frame a container at its available width.</p>
</div>
@use "flair";

.demo-highlight {
	@extend %d-highlight;
	display: inline-block;
	max-inline-size: 100%;
	padding: var(--flair-space-2);
}

.demo-highlight-wrap {
	max-inline-size: 20ch;
}

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Content with trailing actions

Rows wrap when space is limited. The text grows, while actions stay together where they fit. This works for task lists, settings and editable records.

  • Review the deployment checklist
  • A longer record name wraps without hiding its controls
    Edit form example

Standalone recordRead only

Use .row-content for the flexible content and .row-actions for trailing controls. Optional leading content can precede both. --flair-row-gap, --flair-row-actions-gap and --flair-row-content-min configure spacing. Application code owns completion, reordering and persistence.

HTML and Sass 
<ul class="demo-action-list" data-row-example>
  <li>
    <span class="row-content">Review the deployment checklist</span>
    <div class="row-actions"><button type="button" data-row-toggle hidden>Mark complete</button></div>
  </li>
  <li>
    <span class="row-content">A longer record name wraps without hiding its controls</span>
    <div class="row-actions"><a href="/library/forms/">Edit form example</a></div>
  </li>
</ul>
<p role="status" data-row-status></p>
<div class="demo-action-row"><span class="row-content">Standalone record</span><span class="row-actions">Read only</span></div>
