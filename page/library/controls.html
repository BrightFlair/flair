Controls

Native inputs, buttons and the Sass definitions used to style them.

Definitions and dependencies

The entry point style/flair.scss loads definitions without emitting any CSS. Include the default variables once, then extend the objects you need. Fonts are supplied by the application; these examples use the Ubuntu files installed on this website.

  1. variable/index.scss provides defaults() : monochrome colours, spacing, typography and control sizes.
  2. %d-focus-ring defines the keyboard focus outline.
  3. %d-control defines padding, border, background, text and native disabled state. Its focus-visible rule extends %d-focus-ring .
  4. %o-control extends %d-control for text inputs, selects and textareas. It adds full width, placeholder text and read-only presentation.
  5. %o-button extends %d-control for buttons and links. %o-button-primary extends it for the primary action.
  6. %o-choice and %o-range retain native checkbox, radio and range appearance and extend the focus ring. %o-color extends the control decoration with a smaller swatch size. 
@use "path/to/flair/style/flair";

:root {
	@include flair.defaults;
}
.search-input {
	@extend %o-control;
}
.download-link {
	@extend %o-button;
}
.save-button {
	@extend %o-button-primary;
}

Alternatively, include flair.controls() to apply objects to native tags. At the stylesheet root this emits global element defaults; inside a selector it limits them to that region. Hidden and image inputs are excluded. Checkboxes, radios, range and colour inputs receive their own objects. 

.search-area {
	@include flair.controls;
}

Control states

Use the global theme selector to change the page and its examples. Focus a control using the keyboard to inspect its outline. Invalid and read-only examples have dashed and dotted borders respectively. Error text identifies the problem independently of colour.

Buttons and choices

These buttons have no application action. A link styled as a button still navigates. Use native disabled on buttons; styling alone cannot disable a link or prevent an action.

CSS properties

Set properties on the application root or on a containing element. Objects read these values without assigning local defaults that would override inherited settings. The default mixin should be included once per independent theme scope.

--flair-color-*
Text, muted text, surface, disabled surface, border, accent, on-accent and danger colours.
--flair-font-body , --flair-font-size , --flair-font-weight , --flair-line-height
Shared control and field typography. Default: Ubuntu, 1rem, 400, 1.5.
--flair-control-padding-block , --flair-control-padding-inline
Fallback: spacing steps 2 and 3 (0.5rem and 0.75rem).
--flair-control-min-height , --flair-control-radius
Default minimum height: 2.75rem. Radius falls back to the shared radius, initially zero.
--flair-control-background , --flair-control-text , --flair-control-border
Control-specific overrides of the semantic colours.
--flair-focus-color , --flair-focus-width , --flair-focus-offset
Default: accent colour, 3px width, 2px offset.
--flair-button-*
Button background, text and weight, hover background, and primary-action colours. See the complete reference below.

The complete property list, markup contract and extension examples are in the form documentation and docs/forms.md in the repository.
