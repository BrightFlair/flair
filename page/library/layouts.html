Reading layout

This layout deliberately limits text measure to 65ch. The prose pattern itself has no width limit.

Width belongs to the layout

A reading layout limits line length for continuous text. A dashboard may instead use all the available space. Neither decision should be imposed by a button, field or card.

Set --flair-prose-measure on the article layout to change its measure. Forms, grids and surfaces inside other layouts remain fluid.

HTML and Sass 
<article class="demo-article">
	<h3>Width belongs to the layout</h3>
	<p>
		A reading layout limits line length for continuous text. A dashboard may instead use
		all the available space. Neither decision should be imposed by a button, field or
		card.
	</p>
	<p>
		Set <code>--flair-prose-measure</code> on the article layout to change its measure.
		Forms, grids and surfaces inside other layouts remain fluid.
	</p>
</article>
@use "flair";

	@extend %l-article;

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.
