Flair library / 05

Navigation

Page links, section navigation, breadcrumbs and pagination.

Primary navigation

Use ordinary links for page navigation. The current destination is identified with aria-current. On narrow screens, open the menu to reveal its links. Without JavaScript the links remain visible.

  • Navigation
  • Forms
  • Tables
  • Layouts
HTML and Sass 
<nav class="demo-navigation" aria-label="Example library navigation">
	<button type="button" aria-expanded="false" aria-controls="example-navigation-links" data-navigation-toggle hidden>Library menu</button>
	<ul id="example-navigation-links">
		<li><a href="/library/navigation/" aria-current="page">Navigation</a></li>
		<li><a href="/library/forms/">Forms</a></li>
		<li><a href="/library/tables/">Tables</a></li>
		<li><a href="/library/layouts/">Layouts</a></li>
	</ul>
</nav>
@use "flair";

.demo-navigation {
	@extend %p-navigation;
	@include flair.collapsible-navigation($from: 45rem);
}

Pagination

This example moves between library sections. Unavailable destinations are text, rather than disabled-looking links.

  • Previous
  • 1
  • 2
  • 3
  • Next
HTML and Sass

	<ul>
		<li><span aria-disabled="true">Previous</span></li>

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Search result links

A result list is ordinary navigation. Filtering this local example changes only the visible results; Flair does not implement a combobox or perform requests.

  • Forms — fields and validation
  • Layouts — responsive composition
  • Feedback — notices and progress

3 topics. Filtering is available with JavaScript.

Keep links keyboard accessible. --flair-results-max-height defaults to none; result spacing uses --flair-list-padding and --flair-result-link-padding. Empty-state wording and announcements are supplied by the application.

HTML and Sass 
<div data-search-example>
  <label class="demo-field"><span>Find a documentation topic</span><input type="search" data-result-query disabled /></label>
  <ul class="demo-search-results">
    <li><a href="/library/forms/">Forms<span class="result-detail"> — fields and validation</span></a></li>
    <li><a href="/library/layouts/">Layouts<span class="result-detail"> — responsive composition</span></a></li>
    <li><a href="/library/feedback/">Feedback<span class="result-detail"> — notices and progress</span></a></li>
  </ul>
  <p role="status" data-result-status>3 topics. Filtering is available with JavaScript.</p>
</div>
@use "flair";

.demo-search-results { @extend %p-search-results; --flair-results-max-height: 16rem; }
.demo-field { @extend %o-form-field; }

Skip links and visually hidden text

A skip link becomes visible when focused. Visually hidden text remains available to assistive technology.

Skip to the example destination

Use Tab to focus the skip link above. It appears at the top of the viewport.

Read more about accessible navigation

Example destination. Focus can move here without adding it to the normal tab order.

Give skip links real destinations and keep them early in the page order. Do not use visually hidden styling to conceal focusable controls; the skip-link object handles focus visibility separately.

HTML and Sass 
<div class="demo-stack">
  <a class="demo-skip-link" href="#accessible-destination">Skip to the example destination</a>
  <p>Use Tab to focus the skip link above. It appears at the top of the viewport.</p>
  <a href="#accessible-destination">Read more<span class="demo-visually-hidden"> about accessible navigation</span></a>
  <div id="accessible-destination" tabindex="-1"><p>Example destination. Focus can move here without adding it to the normal tab order.</p></div>
</div>
@use "flair";

.demo-skip-link { @extend %o-skip-link; }
.demo-visually-hidden { @extend %d-visually-hidden; }
.demo-stack { @extend %p-stack; }
