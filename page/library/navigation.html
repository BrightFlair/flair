Navigation

Page links, section navigation, breadcrumbs and pagination.

Primary navigation

Use ordinary links for page navigation. The current destination is identified with aria-current.

  • Navigation
  • Forms
  • Tables
  • Layouts
HTML and Sass 
<nav class="demo-navigation" aria-label="Example library navigation">
	<ul>
		<li><a href="/library/navigation/" aria-current="page">Navigation</a></li>
		<li><a href="/library/forms/">Forms</a></li>
		<li><a href="/library/tables/">Tables</a></li>
		<li><a href="/library/layouts/">Layouts</a></li>
	</ul>
</nav>
@use "flair";

.demo-navigation {
	@extend %p-navigation;
}

Breadcrumbs

An ordered list expresses the hierarchy. Separators are hidden from assistive technology.

  1. Flair
  2. /Library
  3. /Navigation
HTML and Sass 
<nav class="demo-breadcrumbs" aria-label="Breadcrumb">
	<ol>
		<li><a href="/">Flair</a></li>
		<li>
			<span class="separator" aria-hidden="true">/</span><a href="/#contents">Library</a>
		</li>
		<li>
			<span class="separator" aria-hidden="true">/</span
			><span aria-current="page">Navigation</span>
		</li>
	</ol>
</nav>
@use "flair";

.demo-breadcrumbs {
	@extend %p-breadcrumbs;
}

Pagination

This example moves between library sections. Unavailable destinations are text, rather than disabled-looking links.

  • Previous
  • 1
  • 2
  • 3
  • Next
HTML and Sass 
<nav class="demo-pagination" aria-label="Example sections">
	<ul>
		<li><span aria-disabled="true">Previous</span></li>
		<li>
			<a
				href="/library/navigation/"
				aria-current="page"
				aria-label="Section 1, Navigation"
				>1</a
			>
		</li>
		<li><a href="/library/disclosures/" aria-label="Section 2, Disclosures">2</a></li>
		<li><a href="/library/tables/" aria-label="Section 3, Tables">3</a></li>
		<li><a href="/library/disclosures/">Next</a></li>
	</ul>
</nav>
@use "flair";

.demo-pagination {
	@extend %p-pagination;
}

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.
