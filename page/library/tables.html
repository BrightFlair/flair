Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Key and value lists

A bordered list of name and value pairs, one row each, with room for a trailing action. Rows alternate shading so a long list stays trackable. This is the editable form: each row owns the control that removes it.

  • STRIPE_SECRET_KEY ••••••••4f21
  • GITHUB_TOKEN ••••••••91ad
  • WEBHOOK_SIGNING_SECRET ••••••••03be

The same pattern, set to read machine output instead. Only theme properties differ; the layout is unchanged.

  • content-typeapplication/json; charset=utf-8
  • cache-controlno-store, max-age=0
  • x-request-id01JQ8Z4M7VYK2R6TQF3H9PWXBN
  • strict-transport-securitymax-age=63072000; includeSubDomains; preload

One definition serves an editor and a viewer because nothing in it decides which it is. --theme-key-value-name fixes the measure of the name column, and an empty list states what is missing from its data-term.
