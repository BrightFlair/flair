Feedback

Notices

Each message names its meaning in text. Static examples do not use alert roles or announce themselves on page load.

Information

Success

Warning

Using these styles

Import flair, include flair.defaults on your application root, then extend the placeholders shown in each example onto your own selectors. The demo- names belong to this website. The containing layout determines available width; theme properties are inherited.

Change the global theme to compare the same markup. Source files, dependencies, property fallbacks and behavioural requirements are documented in docs/library.md.

Values, totals and controls

A metric keeps its value, supporting text and controls on one alignment. Use output for calculated values, and ordinary text for measurements.

Items selected

2

Change this local example with the buttons.

Total: 42

Energy generated

12.5 kWh

An aligned measurement without live announcements.

The value uses %o-value, which can also be extended alone. --flair-metric-align defaults to center; use start or end to align the whole group. --flair-value-size defaults to 3rem. Hidden demonstration buttons are revealed by the website script; a real application supplies its own actions.

HTML and Sass 
<div class="demo-stack">
<div class="demo-metric" data-metric-example>
  <h3>Items selected</h3>
  <output aria-label="Selected item count" aria-live="polite">2</output>
  <p class="metric-detail">Change this local example with the buttons.</p>
  <div class="actions">
    <button type="button" data-metric-step="-1" hidden>Subtract one</button>
    <button type="button" data-metric-step="1" hidden>Add one</button>
  </div>
</div>
<p class="demo-output-row">Total: <output aria-label="Example total">42</output></p>
<div class="demo-metric demo-metric-end">
  <h3>Energy generated</h3>
  <strong class="metric-value">12.5 <small class="metric-unit">kWh</small></strong>
  <p class="metric-detail">An aligned measurement without live announcements.</p>
</div>
</div>
@use "flair";

.demo-stack { @extend %p-stack; }
.demo-metric { @extend %p-metric; }
.demo-metric-end { --flair-metric-align: end; }
.demo-output-row { @extend %p-output-row; --flair-value-size: 4rem; }

Busy, dragging and reveal treatments

These decorations consume application state. They have no dependency on Flux or another JavaScript library.

Preview content stays readable. These controls do not start a request or a drag operation.

--flair-busy-opacity and --flair-drag-opacity control state intensity. --flair-reveal-progress runs from 0 to 1; distance, duration and minimum opacity are configurable. Reveal effects are removed for reduced motion and printing. A Flux consumer can map --flair-reveal-progress: var(--flux-first-visible, 1).

HTML and Sass 
<div data-state-example>
  <div class="demo-state-actions"><button type="button" data-busy-toggle aria-pressed="false" hidden>Toggle busy preview</button><button type="button" data-drag-toggle aria-pressed="false" hidden>Toggle dragging preview</button><button type="button" data-reveal-replay hidden>Replay reveal</button></div>
  <div class="demo-state-panel demo-reveal" aria-busy="false"><p>Preview content stays readable. These controls do not start a request or a drag operation.</p></div>
  <p role="status" data-state-status></p>
</div>
@use "flair";

.demo-state-actions { @extend %p-form-actions; }
.demo-state-panel { @extend %o-card; }
.demo-state-panel[aria-busy="true"] { @extend %d-busy; }
.demo-state-panel[data-dragging="true"] { @extend %d-dragging; }
.demo-reveal { @extend %d-reveal; }
