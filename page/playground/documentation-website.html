First steps

Begin with a small collection of notes. Give each note a clear title and keep related ideas together. This guide follows a simple workspace from its first page to a complete collection.

Organising a workspace

Use folders to group related subjects. Keep shared conventions in one place so that every new page starts from the same foundation.

Keep the structure familiar

Readers should be able to move between a guide and its reference without losing their place. A consistent navigation rail leaves the article free to focus on the subject.

Choose names that explain what a reader will find.

Reference

How should I name a collection?

Use a short, descriptive name that is easy to recognise in navigation.

Can I reorganise it later?

Yes. Update links when moving a page so that readers can still find it.
